# NOT Gate

A KiCad hardware project for a NOT (inverter) gate.

## Project files

- `NOT_GATE.kicad_pro` — KiCad project settings.
- `NOT_GATE.kicad_sch` — circuit schematic.
- `NOT_GATE.kicad_pcb` — PCB layout.
- `Manufacture_FIle/` — Gerber and drill outputs for board fabrication.
- `DRC.rpt` — design-rule check report; the included report records zero violations and zero unconnected pads.

Open `NOT_GATE.kicad_pro` in KiCad to view or edit the design. Regenerate the manufacturing outputs from the PCB if the design changes.
